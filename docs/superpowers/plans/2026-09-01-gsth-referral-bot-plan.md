# План реализации: реферальный бот GShTH

Спецификация: `../specs/2026-09-01-gsth-referral-bot-design.md`

## Шаги

1. **Каркас проекта** — структура пакета `bot/`, `requirements.txt`,
   `.env.example`, `.gitignore`, конфигурация через pydantic-settings.
2. **База данных** — модели `User` и `Referral` (SQLAlchemy 2 async + aiosqlite),
   фабрика сессий, репозиторий; `create_all` при старте, каркас Alembic для
   будущих миграций.
3. **Локализация** — словари текстов uz/ru/en в `bot/locales/`, helper `t()`.
4. **Middleware** — прокидывание сессии БД и загруженного пользователя (+язык)
   в обработчики.
5. **Регистрация** — FSM: выбор языка → имя и фамилия → телефон
   (контакт или ручной ввод с валидацией) → запись в БД.
6. **Подписка и персональная ссылка** — кнопки «Открыть канал» / «Я подписался»,
   проверка `getChatMember`, создание `createChatInviteLink`, инструкция про
   3 друзей.
7. **Подсчёт рефералов** — обработчик `chat_member` канала GShTH: запись
   реферала (дедупликация, запрет самоприглашения), уведомления о прогрессе,
   на 3-м — одноразовая ссылка в закрытый канал (`member_limit=1`).
8. **Главное меню** — для зарегистрированных: статус, моя ссылка, смена языка;
   повторной регистрации нет.
9. **Админка** — `/broadcast` (превью + подтверждение, `copyMessage`, троттлинг,
   отчёт), `/message <tg_id|телефон>`, `/stats`.
10. **Тесты** — pytest: логика рефералов (дедуп, самоприглашение, порог 3)
    на in-memory SQLite.
11. **Деплой** — systemd-юнит, README с инструкцией по BotFather, правам бота
    в каналах и запуску на VPS.

## Отклонение от спеки (мелкое)

Вместо булевого `private_link_sent` храним саму ссылку
(`private_invite_link`, nullable) — «выдана» = «не NULL», и пользователь может
повторно увидеть свою ссылку в меню, если потерял сообщение.
