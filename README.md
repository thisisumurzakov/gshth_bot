# aki-bot — бот Global Shapers Tashkent Hub

Telegram-бот: регистрация (язык uz/ru/en, имя, телефон, дата рождения,
университет или место работы), проверка подписки на канал GShTH и главное меню
с двумя разделами:

- **Проекты** — список активных проектов; карточка с описанием (и фото) и
  регистрацией. Для проекта можно запросить CV и/или мотивационное письмо.
- **Конкурсы** — участник получает уникальную ссылку в канал конкурса;
  побеждает тот, по чьей ссылке вступит больше людей. Вышедшие из канала до
  окончания конкурса не засчитываются. Итоги видят только админы.

Пользователи, зарегистрированные до появления даты рождения и места
учёбы/работы, при следующем обращении к боту сначала заполняют эти поля.

Медиа и файлы на сервере не хранятся: в базе лежат только Telegram `file_id`
(фото, CV, письма), заявки с файлами бот пересылает в чат заявок, CSV-выгрузки
собираются в памяти.

Первоначальная спецификация (реферальная версия) — в `docs/superpowers/`.

## Подготовка

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. Добавьте бота **администратором** в канал GShTH (для проверки подписки) и в
   каждый канал, где будет проходить конкурс, с правом «Приглашать
   пользователей» («Invite users via link»).
3. Узнайте ID канала GShTH (например, переслав пост из канала боту
   [@getidsbot](https://t.me/getidsbot); ID канала начинается с `-100`).
4. По желанию: создайте группу для заявок на проекты, добавьте в неё бота и
   укажите её ID в `APPLICATIONS_CHAT_ID`.

## Запуск локально

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # затем заполните значения
.venv/bin/python -m bot.main
```

База SQLite создаётся автоматически в `data/bot.db` (путь настраивается через
`DB_PATH`). На базе от предыдущей версии бот при запуске сам добавит новые
колонки в `users`; пользователи, у которых была реферальная ссылка, считаются
подтвердившими подписку.

## Тесты

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest
```

## Запуск в Docker

```bash
cp .env.example .env   # заполнить значения
docker compose up -d --build
```

База хранится на хосте в `./data/bot.db` (примонтированный том), поэтому
пересборка и перезапуск контейнера данные не трогают. Логи:
`docker compose logs -f`.

## Деплой на VPS (systemd, без Docker)

```bash
sudo useradd -r -m -d /opt/aki-bot akibot
sudo -u akibot git clone <repo> /opt/aki-bot
cd /opt/aki-bot && sudo -u akibot python3 -m venv .venv && sudo -u akibot .venv/bin/pip install -r requirements.txt
sudo -u akibot cp .env.example .env   # заполнить значения
sudo cp deploy/aki-bot.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now aki-bot
```

Логи: `journalctl -u aki-bot -f`. Бэкап базы — копия файла `data/bot.db`.

## Миграции схемы (Alembic)

Схема создаётся автоматически при первом запуске. При изменении моделей в
будущем:

```bash
.venv/bin/alembic revision --autogenerate -m "описание"
.venv/bin/alembic upgrade head
```

(на уже работающей базе перед первой миграцией один раз выполните
`.venv/bin/alembic stamp head`).

## Админ-команды (в личке с ботом, для ID из `ADMIN_IDS`)

- `/admin` — список команд;
- `/users` — зарегистрированные пользователи: список с постраничным
  переключением и поиском (`/users Иванов`, `/users 901234567`). Карточка
  человека показывает анкету, его заявки на проекты и участие в конкурсах, а
  кнопки присылают его CV и письма и позволяют написать ему;
- `/new_project` — создать проект: название → описание (текст или фото с
  подписью) → какие материалы запрашивать (CV, письмо) → превью;
- `/projects` — проекты: редактирование (название, описание, запрашиваемые
  материалы), список заявок с карточками людей, выгрузка заявок в CSV, все
  файлы заявок одним списком, скрыть/показать;
- `/new_contest` — создать конкурс: канал (переслать пост или @username/ID) →
  название → описание → дата окончания `ДД.ММ.ГГГГ ЧЧ:ММ` по Ташкенту → превью;
- `/contests` — конкурсы: топ-10, редактирование (название, описание, дата
  окончания — уже выданные ссылки продлеваются автоматически), список
  участников с карточками людей, выгрузка в CSV, скрыть/показать;
- `/broadcast` — рассылка всем пользователям (любой тип сообщения, превью и
  подтверждение перед отправкой);
- `/message <tg_id или телефон>` — сообщение конкретному пользователю;
- `/ask_profile` — напомнить дополнить профиль тем, кто ещё не указал дату
  рождения и место учёбы/работы;
- `/stats` — статистика;
- `/cancel` — отменить текущую админ-операцию.
